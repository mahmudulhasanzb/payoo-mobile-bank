# Payoo Mobile Bank

Payoo is a front-end simulation of a mobile banking web application. It is built using HTML, Tailwind CSS with DaisyUI, and vanilla JavaScript to demonstrate core mobile banking functionalities in a user-friendly interface.

## Features

- **User Authentication**: Secure login system to access the banking dashboard.
- **Balance Management**: View available balance updated in real-time.
- **Add Money**: Transfer funds from a simulated bank account.
- **Cashout**: Withdraw money via a simulated agent.
- **Send Money**: Transfer funds to another Payoo user.
- **Pay Bill**: Settle utility bills like electricity, water, and gas.
- **Get Bonus**: Apply a coupon code to receive a bonus amount.
- **Transaction History**: View a log of all your recent transactions.

## Getting Started

To run this project locally, simply clone the repository and open the `index.html` file in your web browser.

```bash
git clone https://github.com/mahmudulhasanzb/payoo-mobile-bank.git
cd payoo-mobile-bank
```
Then, open `index.html` in your preferred browser.
